# Capturas de Web Kuuii

Preparar capturas auténticas de la portada en escritorio y móvil, y de la sección de productos. Mostrar solo las partes necesarias para explicar el diseño, sin ampliar datos de contacto de terceros.

La [demo pública](https://first-web-site-proyect-kuuii.pages.dev/) está enlazada en el caso de estudio. No se incorporaron imágenes fabricadas ni referencias a archivos todavía inexistentes.
