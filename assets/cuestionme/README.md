# Capturas de Cuestion.me

Pendientes de incorporar con una cuenta de demostración y datos ficticios:

1. `bienvenida.png`: portada pública completamente cargada.
2. `editor.png`: cuestionario de ejemplo con preguntas e imágenes.
3. `importacion.png`: análisis de un ZIP de ejemplo sin información personal.
4. `practica.png`: intento con contenido académico ficticio.
5. `resultados.png`: corrección e historial de la cuenta de demostración.

La URL pública respondió durante la revisión, pero permaneció en “Cargando tu sesión”; no se capturó esa pantalla como demostración funcional. No hay enlaces a imágenes inexistentes.

Antes de agregar capturas, comprobar que no aparezcan correos, perfiles, tokens, datos de terceros ni información reservada. Los diagramas reales de arquitectura y flujo están en el [caso de estudio](../../projects/cuestionme/README.md).
