## Organización

- [`projects/`](projects/README.md): catálogo y guía para agregar casos de estudio.
- [`docs/project-template.md`](docs/project-template.md): plantilla para explicar cada proyecto.
- [`assets/`](assets/README.md): capturas, diagramas y material visual de las presentaciones.

Los enlaces apuntan a los repositorios originales, donde se puede consultar su código y documentación. Los casos de estudio se incorporarán progresivamente.

## Qué documentar en cada proyecto

El problema que resuelve, las funcionalidades, las tecnologías utilizadas, las decisiones de diseño, cómo ejecutarlo y las mejoras previstas. La plantilla incluye estos apartados para mantener una presentación consistente.
